Tutorial Completo de Bootstrap

Guía para aprender Bootstrap desde cero

1. Justificación del Framework

Bootstrap es un framework de diseño web que facilita la creación de interfaces modernas, responsivas y coherentes. Su objetivo principal es acelerar el desarrollo de sitios web mediante un conjunto de componentes reutilizables y una amplia colección de utilidades visuales.

Se utiliza en proyectos de todo tipo, desde páginas corporativas hasta paneles de administración, aplicaciones internas, portfolios y prototipos. Su popularidad se debe a su facilidad de instalacion y uso, su documentación clara y su compatibilidad con la mayoría de navegadores modernos.

Bootstrap se apoya en HTML, CSS y JavaScript, y requiere conocimientos minimos de HTML, CSS y Javascript para comenzar.

2. Instalación

Bootstrap puede integrarse en un proyecto de varias formas. La elección depende del tipo de proyecto y del nivel de personalización necesario.

2.1 CDN

La forma más rápida de comenzar consiste en enlazar los archivos CSS y JS desde un servidor externo.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>

2.2 Descarga local

Permite trabajar sin conexión y tener control total sobre los archivos.

2.3 Instalación mediante npm

Recomendada para proyectos con herramientas modernas de construcción.

npm install bootstrap

3. Sistema de Rejilla

El sistema de rejilla de Bootstrap permite organizar el contenido en filas y columnas. Se basa en 12 columnas y se adapta automáticamente al tamaño de la pantalla.

3.1 Ejemplo básico

<div class="row">
  <div class="col-4">A</div>
  <div class="col-4">B</div>
  <div class="col-4">C</div>
</div>

3.2 Breakpoints

Bootstrap utiliza puntos de ruptura para adaptar el diseño a diferentes dispositivos.

  • col-sm
  • col-md
  • col-lg
  • col-xl
  • col-xxl

3.3 Ejemplo responsivo

<div class="row">
  <div class="col-md-6 col-lg-3">Columna</div>
  <div class="col-md-6 col-lg-3">Columna</div>
  <div class="col-md-6 col-lg-3">Columna</div>
  <div class="col-md-6 col-lg-3">Columna</div>
</div>

4. Componentes

Bootstrap incluye una amplia variedad de componentes listos para usar.

4.1 Botones

<button class="btn btn-primary">Aceptar</button>

4.2 Alertas

<div class="alert alert-warning">Advertencia</div>

4.3 Tarjetas

<div class="card">
  <div class="card-body">Contenido</div>
</div>

4.4 Navbar

<nav class="navbar navbar-dark bg-dark">...</nav>

5. Utilidades

Las utilidades permiten aplicar estilos rápidos sin escribir CSS adicional.

5.1 Espaciado

mt-3, mb-4, p-2

5.2 Colores

text-primary, bg-success

5.3 Alineación

text-center, d-flex, justify-content-between
